# マーケティング戦略

対象はコンシェルジュ在籍ホテル(Phase0決定4)。事業計画書の12ヶ月ロードマップ(既存接点起点)を土台に、全国展開を見据えた段階戦略を整理する。

## 最初に狙うセグメント(Phase2仮説)
- 東京・横浜の外資系ラグジュアリーホテル・国内高級ホテル・シティホテル(コンシェルジュ在籍)
- 事業計画書記載の既存接点(Connect経由の関係、世界仮想旅行社経由のホテル網)を優先活用

## セグメント別の課題と訴求(仮説)
| セグメント | 主な課題(仮説) | 訴求メッセージ案 |
|---|---|---|
| 外資系ラグジュアリー | 富裕層の高い期待値、グローバル基準との比較 | 「現地一次情報による、他では出せない提案」 |
| 国内高級ホテル | ブランド基準との整合、紹介責任への慎重さ | 「ホテルの推奨方針・NGリストを反映できるガバナンス」 |
| シティホテル | コンシェルジュの人数・経験のばらつき | 「新人でも一定水準の提案ができる仕組み」 |
| チェーン本部 | 館ごとの品質のばらつき、横展開の効率 | 「本部契約による全館標準化と個別最適化の両立」 |

## 首都圏→全国への展開順序(仮説)
1. 東京・横浜(Dexterの既存知見・体験事業者網が厚い地域)でPoCを実施し、成功事例を作る
2. 関西・北陸などラグジュアリー供給が伸びている地域(事業計画書に「関西ラグジュアリー供給+3,273室」の記載あり)へ拡大
3. 地方部宿泊拡大という政府目標(2030年1.3億人泊)と連動し、地方の体験事業者網・DMO連携を強化しながら地方チェーン・旅館へ展開

## 単館ホテルとチェーン本部の攻略方法(仮説)
- 単館: 現場のコンシェルジュへの直接デモ→支配人への提案という「ボトムアップ+トップ確認」の順
- チェーン本部: 本部のサービス品質・マーケティング担当へ先にアプローチし、1〜2館でのPoCを経て全館展開を提案する「トップダウン」の順(Phase1ヒアリングのペルソナ4質問と連動)

## パートナーシップ
- コンシェルジュ組織・業界団体(例: 国際的なコンシェルジュ団体の日本支部等、詳細はPhase1ヒアリング⑦の回答で実態確認後に検討)との連携可能性
- DMO・観光協会・自治体: 事業計画書に既に記載のある連携先(地域ネットワークの供給源)。マーケティング面でも「自治体との協業実績」は営業資料の信頼性向上に寄与しうる
- 体験事業者: 商品化支援を通じた関係構築が、同時にホテル向け営業の「独自コンテンツ」の源泉にもなる(供給側・需要側の好循環)

## 実行施策
- **導入事例の作り方**: 初期PoCホテルの許諾を得た上で、匿名化または実名(ホテルの意向を尊重)でケーススタディを作成。ブランドを尊重し、公開範囲・表現をホテル側に事前確認するプロセスを必須化する
- **ホワイトペーパー**: 「訪日富裕層の提案力とADR向上の関係」等、事業計画書の市場データ(訪日4,268万人・消費9.5兆円等)を引用しつつDexter視点で編集したもの
- **セミナー・勉強会**: 事業計画書のホテル向けメニュー「月例勉強会」を、見込み客向けの無償セミナーとしても展開(リード獲得と既存顧客向け提供の兼用)
- **無料診断**: 「貴館のコンシェルジュ提案力、簡易診断」のような軽量なリードジェネレーション施策(具体的な設計はPhase3以降)
- **デモ・PoC**: Phase1の「PoC候補ホテル選定基準」に基づき実施
- **業界展示会**: ホテル業界・インバウンド関連の展示会への出展(具体的な展示会名は今回未調査、要デクスター確認)
- **紹介営業・パートナー販売**: 既存契約ホテルからの紹介、DMC・旅行会社経由の紹介
- **PR・コンテンツマーケティング**: 「日本体験知見プラットフォーム」という新カテゴリーの認知形成(事業計画書のポジショニング戦略と連動)

## ネットワーク効果
- 導入ホテルが増えるほど相談履歴・フィードバックが蓄積し、Curator AIの提案精度が上がる(事業計画書のCompounding Loop)という構造を、マーケティングメッセージとしても「早期導入の優位性」として訴求できる
- ただし個別ホテルのデータは他ホテルに開示されない(テナント分離)前提を必ず併記し、「データを他社に見られる」という懸念を先回りして払拭する

## KPI(マーケティング、Phase2仮説、Phase3で精緻化)
- リード獲得数(セミナー・ホワイトペーパー経由)
- 無料診断→デモ移行率
- デモ→PoC移行率
- 導入事例の公開数・ホテル側の許諾取得率
