# セールス戦略

## Ideal Customer Profile(ICP、仮説)
- コンシェルジュが専任で1名以上在籍
- 外国人ゲスト比率が一定以上(目安30%以上、要ヒアリング検証)
- 首都圏に立地、または地方でもインバウンド需要が明確
- ADR向上・顧客体験差別化に経営としての関心がある(事業計画書のホテル業界動向スライドが示す文脈)

## 登場人物
| 役割 | 想定される人物 | 関心事 |
|---|---|---|
| 決裁者 | 支配人、宿泊部門マネージャー、チェーンの場合は本部担当 | ROI、ブランドリスク、コスト |
| 現場利用者 | コンシェルジュ(シニア/ジュニア) | 使いやすさ、提案の質、自分の仕事が奪われない安心感 |
| 推進者(チャンピオン) | ジュニアコンシェルジュまたは変化に前向きなシニアコンシェルジュ | 自分の業務が楽になる実感 |
| 反対・懸念を示しやすい部門 | 情報システム部門(セキュリティ)、法務(紹介責任)、ベテランコンシェルジュ(自分の役割が代替される懸念) | データ管理、契約責任、雇用不安への配慮が必要 |

## 営業プロセス(仮説)
1. **初回面談**: 課題感のヒアリング(Phase1ガイドを流用可能)
2. **業務ヒアリング**: 支配人・コンシェルジュ双方への詳細ヒアリング
3. **デモ**: セルフサービスモードのUIデモ+デスクモードの実績紹介
4. **PoC**: 期間・件数を区切った無償または有償の試行(Phase0決定1に基づく)
5. **効果測定**: Phase2 04で定義した成果指標を基に、導入前後を比較
6. **稟議支援**: 情報システム・法務向けの資料(セキュリティ、データ管理方針)を用意
7. **契約**: Entry/Standard/Premiumいずれかで契約
8. **導入支援**: 初期設定(ホテル別推奨方針・NGリスト等)
9. **利用定着**: 月次勉強会・相談デスクを通じた継続的な関与
10. **契約更新・上位プラン移行**: 研修・商品造成・AI導入等のアップセル
11. **チェーン本部への展開**: 単館での成功実績を基に本部へ提案

## 代表的な反論と回答(仮説、Phase1ヒアリングで実際の反論を収集し更新)
| 反論 | 回答方針(仮説) |
|---|---|
| 「AIが間違った情報を出したら困る」 | 情報源・確認日・信頼度を常時表示し、不確実な場合はAIが断定せず有人デスクへエスカレーションする設計であることを説明。存在しない情報を生成しないガードレールを技術的に説明する資料を用意 |
| 「紹介先でトラブルがあったら誰が責任を取るのか」 | 本タスクの方針上、この論点は専門家確認が必要な未決事項であることを正直に伝え、契約前に責任分界を明文化した契約書・利用規約を用意する(Phase3以降の法務論点) |
| 「コンシェルジュの仕事が奪われるのでは」 | 「目利きを置き換えるのではなく拡張する」という事業コンセプトを、実際の使用感(セルフサービスモードは提案の叩き台であり最終判断はコンシェルジュ)で示す |
| 「個人情報の入力が心配」 | ゲストの氏名・パスポート情報等は入力させないUI設計、入力抑止・マスキング機能を説明 |
| 「月額料金に見合う価値があるか分からない」 | 無償キャンペーンでの体験提供、PoCでの効果測定データを提示 |

## PoC提案書の構成(仮説)
1. 現状の課題(ヒアリングで確認した内容の要約)
2. Dexter Curator AIの提供価値(デスクモード/セルフサービスモードの説明)
3. PoC期間・対象範囲・利用条件(件数上限等)
4. 成果測定方法(導入前基準値の取得方法を含む)
5. PoC終了後の移行条件(有償プランへの移行プロセス)
6. 体制・連絡窓口

## 営業パイプラインKPI(仮説)
- リード数→初回面談化率
- 初回面談→デモ実施率
- デモ→PoC移行率
- PoC→本契約移行率
- 平均商談期間
- 契約単価(プラン別)
- チャーン率(解約率)
- アップセル率(Standard→Premium等)

すべて仮説段階であり、Phase1ヒアリング結果、Phase6以降の実際のPoCデータをもって精緻化する。
