## 示唆

1. **手数料モデルとの対比が差別化の軸になりうる**: OTA各社は一貫して予約手数料型(20〜30%超)であり、Dexterの月額固定型(継続課金型ナレッジサービス)は「販売しない・紹介するだけ」というポジショニングと整合する。ただし、Dexterが将来的に送客手数料モデルを導入する場合(本タスク13章で将来オプションとして整理)、この差別化メッセージが弱まる点に留意。
2. **最大の競合は「無料の代替手段」**: OTA・Google検索よりも、「コンシェルジュ個人の経験・人脈」「既存の業界ネットワーク(Les Clefs d'Or等)」の方が、実質的な競合として強い可能性がある。これらは金銭的コストがゼロであるため、Dexterの価値証明(時間削減・品質向上)がより厳しく問われる。
3. **コンシェルジュ向け既存情報サービスの実態は未調査**: 本分析では裏取りできなかった。Phase1ヒアリングの⑦⑧(相談先・品質判断方法)で実態を把握し、必要であれば個別にWeb調査を追加する。
