# PoC候補ホテルの選定基準

ヒアリング対象(10〜15館想定)の中から、Phase6(MVP実装後の試行利用)に進むPoC候補を選ぶための基準。

## 必須条件
1. コンシェルジュが専任で1名以上在籍している(`00_target_hotel_segments.md`のスクリーニング済み)
2. 外国人ゲスト比率が一定以上(目安: 宿泊者の30%以上、館の実態に応じて調整)
3. ヒアリングで「PoC参加意向: 高」と回答している
4. 意思決定者(支配人 or 本部責任者)がヒアリングに同席、または別途接触できている

## 優先条件(該当数が多いほど優先)
5. Phase1ヒアリングで語られた「困りごと」の総合スコアが高い(=課題感が強く、価値を実感しやすい)
6. 情報システム・法務審査のプロセスが比較的軽い、またはスピード感を持って進められると回答している(⑲の回答)
7. 支払意思が事業計画書の想定レンジ(5〜30万円/月)に近い、または期間限定無償キャンペーンへの参加に前向き
8. デスクモード・セルフサービスモードの両方を試せる体制がある(コンシェルジュがITツールに一定慣れている)
9. 首都圏(東京・横浜)に立地し、Dexterの初期知見(東京の個別アクティビティ例)との親和性が高い
10. フィードバックを積極的に返してくれそうな組織文化(本部を含め改善提案に前向きな姿勢がヒアリング中に見られた)

## 除外条件
- 意思決定に半年以上かかることが判明している(社内審査が極めて重い)
- 専任コンシェルジュが直近で退職・異動予定など、体制が不安定
- 直接の競合他社(類似サービスを提供する企業)との強い関係がある

## 選定プロセス(提案)
1. ヒアリング終了後、`04_recording_sheet_and_evaluation.md`の集計フォーマットを基に、必須条件を満たすホテルを抽出。
2. 優先条件のスコアリング(該当数をカウント)で上位2〜3館を一次候補とする。
3. 分類の異なるホテル(例: 外資系ラグジュアリー1、シティホテル1、チェーン本部1)を最低1館ずつ含めることを目安に、PoCの学びが特定セグメントに偏らないようにする。
4. 最終候補はデクスターに提示し、承認を得てからPoC打診を行う(重大な事業判断のため独断で確定しない)。
