# ヒアリング対象ホテルの分類

Phase0決定4(専任コンシェルジュ不在ホテルを今回のスコープから除外)を踏まえ、Phase1のヒアリング対象は**コンシェルジュ在籍ホテル**に絞る。

## 対象とする分類
1. 外資系ラグジュアリーホテル
2. 国内高級ホテル
3. シティホテル(コンシェルジュ職を設置している館)
4. リゾートホテル(コンシェルジュ職相当を設置している館)
5. ブティックホテル(少人数でコンシェルジュ機能を担うスタッフがいる館)
6. 旅館(客室係・仲居がコンシェルジュ相当の提案業務を担うケースがあれば含める。設置有無は事前スクリーニングで確認)
7. 単館ホテル
8. ホテルチェーン(本部・複数館共通の意思決定層)

## 今回対象外(将来検討)
- ビジネスホテル(専任コンシェルジュ不在が通例)
- 専任コンシェルジュがいないホテル全般(フロントスタッフ・インフォメーション担当が主体の館)

## 事前スクリーニング質問(依頼時に確認)
ヒアリング打診の際、以下を事前確認し対象可否を判断する:
- 貴館にはコンシェルジュ職(またはそれに相当し、外国人ゲストへの体験提案を主業務とする担当)が在籍していますか。
- 何名体制ですか。専任/兼任のいずれですか。

上記でコンシェルジュ不在と判明した場合は、今回のヒアリング対象から外し、次フェーズ以降の拡張検討リストに記録する。

## 目標サンプル数(提案、デクスターと要調整)
- 合計 10〜15館(うち外資系ラグジュアリー2〜3、国内高級2〜3、シティホテル3〜4、リゾート2、旅館1〜2、ブティック1〜2、チェーン本部1〜2)
- 首都圏(東京・横浜)を中心に、地方1〜2館を比較対象として含める
