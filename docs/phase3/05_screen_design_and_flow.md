# 画面設計・画面遷移

## 画面遷移の全体像(テキスト表現)

```
[ログイン]
  → (ホテル利用者) [ホテル用ホーム]
        → [クイック相談] → [AIによる追加質問] → [候補一覧] → [候補比較] → [体験詳細]
                                                            → [ゲスト向け提案文] → [多言語表示]
        → [詳細条件入力] → (同上、候補一覧以降へ合流)
        → [候補一覧/提案文] → [有人相談依頼] → [相談履歴](ステータス確認)
        → [相談履歴] → [お気に入り] / [フィードバック]
        → (管理者のみ) [ホテル管理者画面]
  → (Dexter運用者) [デクスター運用管理画面]
        → [有人相談キュー](相談履歴画面のDexter向けビュー) → 代行入力(クイック相談〜提案文と同じ画面をDexter向け権限で使用)
        → [体験情報編集] → [情報更新・期限管理]
        → [利用状況分析]
        → [誤情報報告]対応
```

**設計上のポイント(Phase0決定2の反映)**: 「クイック相談」「詳細条件入力」「候補一覧」「候補比較」「体験詳細」「ゲスト向け提案文」の各画面は、ホテルコンシェルジュが直接操作する場合(セルフサービスモード)と、Dexter運用者が担当ホテルの代わりに操作する場合(デスクモード代行入力)の**両方から同じ画面群を利用する**。権限(`04_permissions.md`)によって「誰の代わりに入力しているか」の表示と操作範囲が切り替わる。

## 画面定義

### 1. ログイン
- 利用者: 全ロール
- 目的: 認証
- 主要操作: ID/パスワード入力(将来SSO対応を考慮)
- 表示項目: ロゴ、入力フォーム、パスワード再設定リンク
- エラー・例外: 認証失敗、アカウントロック
- 権限制御: なし(ログイン前)

### 2. ホテル用ホーム
- 利用者: ホテル一般利用者・管理者
- 目的: 主要機能への入口、直近の相談状況の把握
- 主要操作: クイック相談開始、相談履歴確認
- 表示項目: 未回答の相談件数、直近のフィードバック依頼、お知らせ
- エラー・例外: データ取得失敗時のフォールバック表示
- 権限制御: 自ホテルのデータのみ表示

### 3. クイック相談
- 利用者: ホテル一般利用者(セルフサービス) / Dexter運用者(代行入力)
- 目的: 最小入力での候補検索開始
- 主要操作: 自由記述入力、テーマ/エリア選択(任意)
- 表示項目: 入力欄、過去の類似相談へのショートカット
- エラー・例外: 入力が空の場合の警告、個人情報入力の検知時は警告表示し送信をブロック
- 権限制御: 入力者ロールを自動記録

### 4. 詳細条件入力
- 利用者: 同上
- 目的: 条件を絞った検索(地方2泊3日案等の複雑な依頼向け)
- 主要操作: 人数・日程・予算・対象ゲスト属性等の入力
- 表示項目: 各条件フィールド
- エラー・例外: 矛盾する条件(例: 予算と希望内容の不整合)への警告
- 権限制御: クイック相談と同様

### 5. AIによる追加質問
- 利用者: 同上
- 目的: 曖昧な要望を具体化する
- 主要操作: AIが提示した質問への回答
- 表示項目: 質問文、選択肢または自由記述欄
- エラー・例外: 質問への回答をスキップした場合、確信度が下がる旨を表示
- 権限制御: 同上

### 6. 候補一覧
- 利用者: 同上
- 目的: 検索結果の確認
- 主要操作: 候補の絞り込み、詳細画面への遷移、比較への追加
- 表示項目: 候補カード(名称・概要・信頼度区分・確認日を一覧表示)
- エラー・例外: 候補ゼロ件時、有人デスクへの相談を促すメッセージ
- 権限制御: 自ホテルの推奨方針(NGリスト)でフィルタ済みの結果のみ表示

### 7. 候補比較
- 利用者: 同上
- 目的: 複数候補を並べて比較
- 主要操作: 候補の選択・比較項目の切替
- 表示項目: 料金帯・所要時間・対応言語・信頼度等の比較表
- エラー・例外: 比較対象が1件のみの場合は比較表非表示
- 権限制御: 同上

### 8. 体験詳細
- 利用者: 同上
- 目的: 個別体験の詳細確認
- 主要操作: 提案への追加、フィードバック参照
- 表示項目: 概要、料金帯、所要時間、アクセス、予約方法、キャンセル条件、リスク・注意事項、情報源、最終確認日、確認者、信頼度区分、**要確認事項**
- エラー・例外: 有効期限切れの体験は「要再確認」の警告を強調表示
- 権限制御: 同上

### 9. ゲスト向け提案文
- 利用者: 同上
- 目的: ゲストに提示する文章の生成・編集
- 主要操作: 生成、手動編集、コピー
- 表示項目: 生成文、編集用テキストエリア、元になった情報源へのリンク
- エラー・例外: 生成失敗時は再試行またはデスクモードへのエスカレーション導線を表示
- 権限制御: 編集はホテル利用者・Dexter運用者双方可、最終版の公開判断はコンシェルジュ

### 10. 多言語表示
- 利用者: 同上
- 目的: 日本語・英語(MVP)での並記確認
- 主要操作: 言語切替
- 表示項目: 原文・翻訳文の対比表示
- エラー・例外: 翻訳品質に不安がある場合の注意書き表示
- 権限制御: 提案文画面に準ずる

### 11. 有人相談依頼
- 利用者: ホテル一般利用者
- 目的: デスクモードへのエスカレーション
- 主要操作: エスカレーション理由の選択・補足入力、緊急度設定
- 表示項目: これまでの会話履歴の引き継ぎ確認
- エラー・例外: 重複依頼の警告(同一相談案件への複数エスカレーション)
- 権限制御: 自ホテルの相談案件のみ

### 12. 相談履歴
- 利用者: ホテル利用者(自ホテル分) / Dexter運用者(担当ホテル分、デスクモードのキューとして)
- 目的: 過去・進行中の相談の一覧・検索
- 主要操作: ステータスフィルタ、検索
- 表示項目: 相談一覧(ステータス・緊急度・入力者ロール表示)
- エラー・例外: なし
- 権限制御: テナント分離の原則を適用

### 13. お気に入り
- 利用者: ホテル一般利用者
- 目的: よく使う体験の保存
- 主要操作: 追加・削除
- 表示項目: 保存済み体験一覧
- エラー・例外: なし
- 権限制御: 個人単位

### 14. フィードバック
- 利用者: ホテル一般利用者
- 目的: 体験後のゲスト反応登録
- 主要操作: 評価入力、自由記述
- 表示項目: 対象提案の情報、入力フォーム
- エラー・例外: 未実施の体験への誤登録を防ぐ確認ダイアログ
- 権限制御: 自ホテルの提案のみ

### 15. ホテル管理者画面
- 利用者: ホテル管理者
- 目的: 推奨方針・NGリスト設定、ユーザー管理、利用状況確認
- 主要操作: 設定編集、ユーザー招待・削除
- 表示項目: 現在の設定一覧、利用状況サマリ
- エラー・例外: 設定の不整合(NGリストと既存提案の矛盾)への警告
- 権限制御: ホテル管理者のみ

### 16. デクスター運用管理画面
- 利用者: Dexter運用者・システム管理者
- 目的: 有人相談キュー管理、全体状況の把握
- 主要操作: 案件アサイン、SLA状況確認
- 表示項目: 全担当ホテルの案件一覧、SLA超過アラート
- エラー・例外: SLA超過時のエスカレーション通知
- 権限制御: Dexterスタッフのみ、担当ホテル範囲で制御

### 17. 体験情報編集
- 利用者: Dexter運用者(下書き作成)・システム管理者(承認)
- 目的: 体験データの登録・編集・承認
- 主要操作: 新規登録、編集、承認申請、承認/差し戻し
- 表示項目: 体験の全属性(データモデル参照)
- エラー・例外: 必須項目(情報源・確認日)未入力での公開申請を拒否
- 権限制御: 下書き編集はDexter運用者、公開承認はシステム管理者のみ

### 18. 情報更新・期限管理
- 利用者: Dexter運用者・システム管理者
- 目的: 有効期限切れ・更新が必要な体験の一覧管理
- 主要操作: 更新作業への着手、期限延長
- 表示項目: 期限切れ間近/切れの体験一覧
- エラー・例外: 期限切れ体験が検索結果に混入しないことを保証する仕組みと連動
- 権限制御: Dexterスタッフのみ

### 19. 利用状況分析
- 利用者: ホテル管理者(自ホテル分)、Dexterシステム管理者(全体)
- 目的: KPI確認(`07_kpi.md`参照)
- 主要操作: 期間指定、指標切替
- 表示項目: 相談件数推移、エスカレーション率、提案採用率等
- エラー・例外: データ不足期間の注記
- 権限制御: テナント分離を適用

### 20. 誤情報報告
- 利用者: ホテル利用者、Dexter運用者
- 目的: 誤った情報の報告・修正依頼
- 主要操作: 報告理由入力、対象データの指定
- 表示項目: 報告フォーム、過去の報告状況
- エラー・例外: 重複報告の検知
- 権限制御: 報告は誰でも可、修正反映はDexterシステム管理者の承認を経る
