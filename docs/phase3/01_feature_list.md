# 機能一覧(MVP必須 / ヒアリングで検証 / 後日追加)

Phase0の「MVPに含める/含めない」を、Phase1ヒアリング実施を前提に更新した最終分類。凡例: **必須**=MVP(Phase6)に含める / **検証**=Phase1ヒアリング結果次第 / **後日**=MVP後の拡張。

## MVPに含めないもの(Phase0からの確定事項、変更なし)
- 予約・決済機能
- 送客・紹介手数料の自動計算
- PMS/CRM/Slack/Teamsとの本格連携(APIの型だけ設計)
- Virtual Travel Japan 2.0関連機能
- BTM・海外旅行会社・学校法人・体験事業者/民泊向け専用UI
- 独自LLMの学習・ファインチューニング
